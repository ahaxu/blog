## Oát đờ heo "arch linux omarchy"

### Cài đặt

- Tải omarchy https://iso.omarchy.org/omarchy-online.iso
- Tạo usb boot
- Theo hướng dẫn sau: `https://learn.omacom.io/2/the-omarchy-manual/96/manual-installation`
- Sau khi cài xong arch linux: `curl -fsSL https://omarchy.org/install | bash`

### Sử dụng (cơ bản)

- Thao tác với phím tắt
- Chỉnh màu mè (themes ...)
- Trình cài đặt phần mềm
- Độ lại short keys, key bindings (`./config/hypr`)

### Độ

- [Logo, screensaver](https://github.com/search?q=repo%3Abasecamp%2Fomarchy%20logo.txt&type=code)
- [Custom build iso](https://github.com/omacom-io/omarchy-iso/blob/main/README.md)
- Dùng plymouth độ splash screen khi boot
